# ADR 0005：一键安装脚本的范围与策略

- **状态**：已接受
- **日期**：2026-09-17（决策完成时）

## 背景

教程需要一个可执行的基础铺装路径（参考项目使用 `cp -an` 合并不覆盖）。本仓库定位纯文档，但提供可选脚本以提升可复现性。

## 决策

1. 提供 **`scripts/kickstart-install.sh`** 单脚本，参数化两种部署策略：
   - `--fresh`：按全新部署，直接覆盖铺装到 `~/.pi/agent`。
   - `--merge`：检测到既有 `~/.pi/agent` 时，用合并语义（`cp -an`）补缺不覆盖。
2. 脚本**只做基础文件铺装**（复制 models.json / settings.json / mcp.json 等配置模板），**不自动执行** `pi install` 安装扩展。
3. 各扩展的 `pi install ...` 命令留在对应 `docs/installation-*.md`，由读者在文档指引下手动执行，避免脚本在未装好 pi 本体前就去调 pi。

## 后果

- 脚本低侵入、可复现基础配置。
- 扩展按文档手动安装，步骤透明可审计。
